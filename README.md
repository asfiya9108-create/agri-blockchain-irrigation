# 🌱 Agriculture Blockchain Irrigation System

## 📌 Project Overview

The Agriculture Blockchain Irrigation System is a smart agriculture project designed to monitor soil moisture and water usage and help manage irrigation efficiently.

The system uses soil moisture sensor data to evaluate the condition of agricultural fields. Based on the soil moisture level, the system determines whether irrigation should be started, maintained, or stopped.

Blockchain technology is used to store irrigation records in a secure and tamper-resistant way. This helps maintain reliable records of soil moisture, water usage, and irrigation activities.

## ✨ Features

- 🌱 Soil moisture monitoring
- 💧 Water usage monitoring
- 🚿 Automatic irrigation evaluation
- ⛓️ Blockchain-based irrigation records
- 📊 Irrigation and soil-moisture history
- 🤖 Smart contract-based irrigation decisions
- 🌡️ Sensor data simulation
- 🎛️ Irrigation controller
- 🖥️ Web-based dashboard
- 🔐 Secure and organized project structure
